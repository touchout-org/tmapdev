Getting Started

Click the New Map button and type an address or place name, then Search, to create your first map, centered on that location — this becomes the "anchor pin." Once a map exists, the New Map button is replaced by a Map Menu with New Map and New Pin items: New Pin adds another location to the current map (or, if it's too far away, offers to start a new map centered there instead) via its own Search button, or drops a custom-named pin right at your cursor. If the cursor is already on a pin, the same menu item and hotkey open Edit Pin instead, to rename or delete it.

* * note: There are 6 keys on the DotPad. The following documentation uses Perkins-style dot number notation to describe commands entered from the DotPad itself.

Connecting the Dot Pad

Use the Connect Dot Pad button (top of the page) to pair with a physical Dot Pad over Bluetooth — this requires Chrome, since Web Bluetooth isn't available in other browsers.

Steps to connect:

  1. Turn on the Dot Pad and wait for it to complete power-up.
  2. Press the "Connect Dot Pad" button on the web page.
  3. Shift-Tab twice to focus the device selection control.
  4. Press Down arrow to select the Dot Pad device.
  5. Press Enter to connect. If the connection is successful, a grid or map will appear on the display.
  6. Once connected, Disconnect Dot Pad appears at the bottom of the Main Menu.

Street Abbreviation Key

Lists every pin and street currently visible on the map — pins first with their marker, then streets alphabetically, each paired with its 3-character braille label — so you can look up what a label stands for without hunting for it with the cursor. New Map

Opens via the New Map button (before any map exists) or the Map Menu's New Map item (once one does), or the n hotkey. Search for a location and it always becomes the center of a fresh map, replacing whatever's currently showing (which is added to your Map History automatically) — Cancel closes the dialog without doing anything.

New Pin

Opens via the Map Menu's New Pin item, or the p hotkey (only available once a map exists, same as the menu item) — unless the cursor is already on a pin, in which case both open Edit Pin instead (see below). DotTMAP looks up nearby businesses and attractions from Google, plus the closest street address, and lists them alphabetically; the first one fills in the name field automatically, selected, so just starting to type replaces it. Up/Down step through the rest of the suggestions the same way (they stop at either end, no wraparound). If you start typing before the suggestions arrive, your text is left alone — press Down to get the first suggestion. Drop Pin Here always drops a new pin at the cursor's current position, no matter which suggestion is showing; Search instead treats the field's text as a location to add to the map (or, if it's too far away, offers to start a new map there instead); Cancel adds nothing.

Edit Pin

Opens instead of New Pin — same Map Menu item, same p/a hotkeys — whenever the cursor is already on a pin, anchor or additional. The name field starts filled in with the pin's current name. OK renames it (renaming the anchor also updates the page heading and browser tab title); Cancel leaves it unchanged. Delete Pin — shown for every pin except the anchor, which a map always needs — permanently removes the pin from the map; unlike removing a pin in Map Customization, this can't be undone from Hidden Features.

Display Preferences

Opens from the Main Menu. Every control here applies immediately — there's no OK/Cancel, just a Done button to close it. Includes Braille Translation, the four braille label checkboxes, Units (Imperial/Metric — affects Scale and how distances are announced), Scale, Pan Amount, Automatic simplification (see below), and Cursor Solo Timeout (1/2/3/5 seconds, or None) — how long cursor-only mode stays on before automatically restoring everything on its own; changing it while cursor-only mode is already active and counting down takes effect immediately, restarting the countdown under the new duration.

Automatic Simplification

Checked by default in Display Preferences. When on, DotTMAP keeps Map Complexity at a readable level on its own — hiding smaller streets when the map gets too dense, and showing more detail again when there's room — so you don't need to manage Map Complexity by hand. It re-evaluates on a new search, a scale change, or a Units change; it never touches panning, Edit Map's per-item hide/show, or braille label zones. Picking a Map Complexity level yourself (1-4, x, or the Map Customization dialog) always takes effect right away — automatic adjustment just may change it again the next time it runs. Turn the setting off in Display Preferences for fully manual control, same as before this feature existed.

Map Customization

Opens from the Main Menu (formerly "Edit map..."). Shows or hides individual pins and streets, lists everything currently hidden in one place, and includes the Map Complexity control — every action here takes effect immediately, with no Save/Cancel step.

My Archives

Opens from the Main Menu. Saved Maps lets you explicitly save the current map under a name with optional notes, then reload, edit, or delete it later — click the Name or Date/Time column header to sort. Recent Maps automatically keeps the last 10 maps you've visited, current map always on top; Clear History empties this list without touching anything you've saved.

The dialog itself opens whether you're signed in or not, but Saved Maps and Recent Maps both require signing in (Login, Main Menu) to store or show anything beyond the current map — sign in first if either section shows a prompt instead of your maps.

Login / Logout

Opens a Google sign-in popup (Login) or signs you out (Logout, shown in its place once signed in) — both live at the same spot in the Main Menu. Signing in only unlocks the Firestore-backed parts of My Archives (Saved Maps and Recent Maps); every other feature works exactly the same either way.

Release Notes

Opens from the Main Menu, just after Help. Lists user-facing changes by date, newest first, so you can see what's new since you last checked.
