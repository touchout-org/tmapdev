August 2, 2026

  • Redesigned how you start a map and add pins: the always-visible search field at the top of the page is gone. Use n to open the New Map dialog and search for a location to get started. Use p to open the New Pin dialog and add a pin to the current map — or, if the cursor is already on a pin, p opens the new Edit Pin dialog instead, to rename or delete it. Both dialogs are also reachable from the Map Menu with a mouse or screen reader. This simplifies and clarifies the different ways to search, and cleans up a cluttered main page.
    • Open New Map: n key.
    • Open New Pin / Edit Pin: p key.
  • Replaced the on-screen Pins list with a Goto Pin button: a small pin icon at the bottom of the map lets mouse users step through pins with a click. Keyboard and Dot Pad users still use ./, or dot 4/dot 1, unchanged.
  • Added a Help button to the page footer, plus h or ? hotkeys to open Help from anywhere — makes the Help guide easier to find and open for everyone.

July 27, 2026

  • Added Automatic Simplification: DotTMAP now keeps Map Complexity at a readable level on its own — hiding smaller streets when the map gets too dense, and showing more detail again when there's room — so you don't need to manage Map Complexity by hand. It re-evaluates on a new search, a scale change, or a Units change, and picking a Map Complexity level yourself always still takes effect right away. Checked by default; turn it off in Display Preferences ("Automatic simplification") for fully manual control, same as before this feature existed.
  • Settings dialog polish: the Done button now sits at the top of Display Preferences (and receives focus when it opens), matching every other dialog in the app.

July 26–27, 2026

  • Added the Street Abbreviation Key: a dialog listing every POI and street currently visible on the map, so you can look up what a street's 3-character braille label stands for without hunting for it with the cursor. POIs are listed first (with their marker), then streets alphabetically, each as [abbreviation]--[name]. The same list also renders as real braille directly on the graphics display, temporarily standing in for the map — closing the dialog puts the map right back.
    • Open Street Abbreviation Key: / key, or dots 3+4 on the Dot Pad.
    • Scroll the list on the Dot Pad: dots 4+5+6 (forward), dots 1+2+3 (backward).
    • Close Street Abbreviation Key: Escape key, or dots 1+2+3+4+5+6 on the Dot Pad.

July 25–26, 2026

  • Location search now uses Google's search engine instead of OpenStreetMap's Nominatim, for more reliable address and place lookups.
  • When a search doesn't find an exact match, DotTMAP now shows a "Did you mean...?" list of suggested places to choose from, instead of just failing.
  • Drop Pin's nearby-name suggestions (shown when adding a Custom POI) now come from Google too, for more relevant results near your cursor.
  • Replaced the on-screen Move Map buttons with edge bars — click along the top, bottom, left, or right edge of the map to pan one step in that direction.
  • Added a Cursor Solo Timeout: once Cursor Only mode is turned on, it can now turn itself back off automatically after a short delay. The delay (1, 2, 3, or 5 seconds) is adjustable under Display Preferences → Cursor Solo Timeout, or can be turned off entirely by choosing "None" — in that case Cursor Only mode stays on until you explicitly turn it back off yourself to bring the street network back.
    • Toggle Cursor Only mode: 0 key, or dots 3+5+6 on the Dot Pad.
  • Added a hotkey to quickly step through Map Complexity levels one at a time, from most to least detail.
    • Cycle Map Complexity: x key, or dots 1+3+4+6 on the Dot Pad.
  • Added Dot Pad key combos for toggling braille labels without touching the keyboard:
    • Toggle Top Labels: dots 1+3+6 (the letter "u")
    • Toggle Bottom Labels: dots 1+3+4 (the letter "m")
    • Toggle Left Labels: dots 2+4+5+6 (the letter "w")
    • Toggle Right Labels: dots 1+2+3+5 (the letter "r")
